# Ques. What is event handling in the context of android development?

- Event handling is the process of detecting and responding to actions or events generated by the user, the Android system, or other components of an application.
- An event is something that happens in an application, such as **clicking a button, touching the screen, typing text, selecting an item, changes a checkbox, or scrolling**. Android provides **event listeners and callback methods** to handle these events and perform the required action.

- Common Android Events
  - **Click event** – when a user clicks a button.
  - **Touch event** – when a user touches the screen.
  - **Long-click event** – when a user presses and holds a view.
  - **Text-change event** – when text in an input field changes.
  - **Check-change event** – when a checkbox or switch changes its state.

- **Basic Process**
  ```
     User performs an action
              ↓
         Event occurs
              ↓
     Event Listener detects it
              ↓
     Callback method is called
              ↓
    Required action is performed
  ```

- Example:-
  ```Java
    Button button = findViewById(R.id.button);
    
    button.setOnClickListener(v -> {
        Toast.makeText(this,
            "Button Clicked",
            Toast.LENGTH_SHORT).show();
    });
  ```

# Ques. Importance of Listeners in Event Handling

- A listener watches for an event and tells the application when that event happens.
- For example, when a user clicks a button, an OnClickListener detects the click and executes the required code.

- Common Event Listeners
  | Event |	Listener |
  |-------|----------|
  | Button Click |	OnClickListener |
  | Long Click |	OnLongClickListener |
  | Touch |	OnTouchListener |
  | Key Press |	OnKeyListener |
  | Checkbox/Radio Button Change |	OnCheckedChangeListener |
  | Text Change |	TextWatcher |
  | Focus Change |	OnFocusChangeListener |

- **Importance of Listeners**
  - **Detect user actions:**  Listeners detect actions such as clicking, touching, typing, scrolling, etc.
  - **Make applications interactive:** They allow the application to respond to what the user does.
  - **Separate event detection from application logic:** The listener detects the event, while the code inside the callback decides what to do.
  - **Handle different types of events:** Android provides different listeners for different events.
  - **Improve user experience:** Applications can immediately respond to user actions.

# Important Types of Listeners

| Listener | Event handled | Main method |
|---|---|---|
| **`OnClickListener`** | Click on a View/Button | `onClick()` |
| **`OnLongClickListener`** | Long press on a View | `onLongClick()` |
| **`OnTouchListener`** | Touch events | `onTouch()` |
| **`OnKeyListener`** | Keyboard/key events | `onKey()` |
| **`OnFocusChangeListener`** | Focus changes | `onFocusChange()` |
| **`OnCheckedChangeListener`** | Checkbox/Switch state changes | `onCheckedChanged()` |
| **`OnItemClickListener`** | Item click in AdapterView-based widgets | `onItemClick()` |
| **`OnItemSelectedListener`** | Item selection | `onItemSelected()` |
| **`TextWatcher`** | Text changes | `onTextChanged()` |
